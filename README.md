# web-application-defacement-investigation
A web application hosted at startrek.com—a placeholder name used for legal and privacy reasons—was defaced by an attacker. Splunk was used to analyze network intrusion detection, HTTP, and IIS logs to reconstruct the attack.
The investigation followed the Lockheed Martin Cyber Kill Chain framework, focusing on:

    Reconnaissance and scanning.

    Identification of the targeted web server.

    Web application vulnerability assessment.

    Credential attacks.

    Successful authentication.

    Malicious file upload.

    Potential web-server compromise and defacement.
